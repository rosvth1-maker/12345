# รายงานการพัฒนา TS Dark World Windows Client — รุ่นแรก

วันที่: 17 สิงหาคม 2569

## ผลงาน

- สร้างซอร์ส C#/.NET 9 แบบแยก 7 โครงการและชุดทดสอบ
- สร้าง Windows UI ภาษาไทยด้วย WPF
- รองรับตั้งค่า Host, Port และ Client Version
- สร้าง TCP Client ที่เชื่อมต่อและรับข้อมูลแบบต่อเนื่อง
- สร้าง Frame Codec ตรงกับ C# Server: header `C0 91`, XOR `AD`, little-endian
- รองรับ Handshake `main=0, sub=0`, เวอร์ชัน 258
- รองรับ Login `main=1, sub=1`, ช่องบัญชีและรหัสผ่าน 20 ไบต์
- อ่านผล Login และรายชื่อตัวละครเบื้องต้น
- สร้างพื้นผิวเกมต้นแบบ คลิกเมาส์เพื่อเปลี่ยนตำแหน่งตัวละคร
- สร้างเครื่องมือสแกนทรัพยากรตัวเกมไทยเดิมแบบอ่านอย่างเดียว
- เพิ่มไฟล์ตั้งค่า JSON และเอกสารใช้งาน

- ส่งคำสั่งเข้าเกมและเดินจริงกับเซิร์ฟเวอร์
