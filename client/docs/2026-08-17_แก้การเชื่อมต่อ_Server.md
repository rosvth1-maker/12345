# บันทึกการแก้การเชื่อมต่อ TS Dark World Server

## ก่อนทำ

- เป้าหมาย: ทำให้ Windows Client เชื่อมต่อกับ Server ใน `TS Dark World online Server new 2026` ได้ถูกต้อง
- ไฟล์ที่เกี่ยวข้อง: MainWindow.xaml, MainWindow.xaml.cs, PacketIO.cs, TcpGameClient.cs และชุดทดสอบ
- สำรองไว้ที่ `backups\2026-08-17_server_connection_fix`

## ผลการเปรียบเทียบ

- Server ใช้ Character opcode `main=3`; Client เดิมรอ `main=2`
- Server ใช้ Keepalive `main=10, sub=1` ทุก 20 วินาที; Client เดิมยังไม่มี
- Server เลือกตัวละครด้วย `main=3, sub=1` และตอบ Enter Game ด้วย `main=3, sub=2`

## สิ่งที่แก้

- แก้การอ่าน Character List เป็น `main=3, sub=1`
- เพิ่ม Keepalive ทุก 20 วินาที
- เพิ่มปุ่มเข้าเกมด้วยตัวละครแรกและแพ็กเก็ต Select Character
- เพิ่มการอ่านข้อมูล Enter Game เบื้องต้น
- ปรับการปิด TCP Client เมื่อ Receive Loop สิ้นสุด
- เพิ่มค่าคงที่ opcode ฝั่ง Client
- เพิ่ม Protocol tests สำหรับ Keepalive และ Select Character
